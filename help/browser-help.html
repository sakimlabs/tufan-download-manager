Tufan Download Manager - Browser Extension Help

Version 4.0.0

📦 Installation

Chrome / Edge / Brave / Opera / Vivaldi:
  1. Open chrome://extensions/
  2. Enable Developer mode (top right)
  3. Click Load unpacked
  4. Select folder: D:\Tufan Download Manager\Release\extension\chromium\
Firefox:
  1. Open about:debugging#/runtime/this-firefox
  2. Click Load Temporary Add-on
  3. Select file: D:\Tufan Download Manager\Release\extension\tdm-firefox.xpi (OR load manifest.json from firefox\ folder)
Note: Firefox 109+ required for MV3 support. Update Firefox if using older versions.

⚙️ Usage

  • Click the Tufan icon in toolbar
  • Extension auto-connects to running app
  • Downloads, videos, torrents auto-intercepted
  • Popup shows download status and controls

🔧 Troubleshooting

Connection failed? Ensure app is running in background (system tray icon visible)
Downloads not intercepting? Check app Settings → Browser Integration

🔐 Permissions

The extension requests these permissions for full functionality:

  • downloads - Manage browser downloads
  • nativeMessaging - Communicate with Tufan app
  • contextMenus - Add right-click options
  • cookies - Access video site cookies for download
  • - Work on all websites
